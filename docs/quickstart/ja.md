# Playlister

OBS Studio 33 以降用のプレイリストソースです。動画・音声・画像ファイル、フォルダー、プレイリストファイル、Web アドレスを OBS 自身のメディアソースを使って順番に再生し、リストを編集しても再生中のクリップは最初からやり直しになりません。

<img src="../../docs/images/quick-start-steps.svg" alt="Playlister の 3 ステップ: 1、インストールして OBS を再起動。2、ソースで + を押し、Playlister を選んで OK を押す。3、プレイリストの右の + を押し、ファイル、フォルダー、Web アドレスを追加。シーンがプログラムに入ると再生されます。" width="900">

1. **インストール。** [最新リリース](https://github.com/jbrick2070/obs-playlister/releases/latest)からお使いのシステム用のファイルをダウンロードして実行し(詳しくは英語の [Install](../../README.md#install))、OBS を再起動します。
2. **ソースを追加。** OBS の **ソース** で **+** を押し、**Playlister** を選んで **OK** を押します。
3. **再生するものを追加。** 開いたウィンドウで **プレイリスト** の右にある **+** を押し、**ファイルを追加**(動画、音声、画像、プレイリストファイル)、**ディレクトリを追加**(フォルダー。新しいファイルは自動で追加されます)、または **パス/URLを追加**(Web アドレス)を選びます。**OK** を押します。

これで完了です。シーンが **プログラム** に入るとすぐに再生されます。設定の変更は不要です。リストはループし、フォルダーは監視され、行がファイル、フォルダー、プレイリストファイル、Web アドレスのどれかは Playlister が自動で判断します。

**スタジオモード** では、新しいソースは **プレビュー** のシーンで待機します。そのシーンを **フェード** または **カット** で **プログラム** に送るまで、**状態** には「待機中: シーンがプログラムに入ると再生されます。」と表示されます。
