# Playlister

適用於 OBS Studio 33 及更新版本的播放清單來源。透過 OBS 本身的媒體來源依序播放影片、音訊和影像檔案、資料夾、播放清單檔案和網址，編輯清單不會讓正在播放的片段重新開始。

<img src="../../docs/images/quick-start-steps.svg" alt="三步使用 Playlister：1，安裝並重新啟動 OBS；2，在「來源」中按 +，選擇 Playlister，然後按「確定」；3，按「播放清單」右側的 +，新增檔案、資料夾或網址。其場景進入展示後開始播放。" width="900">

1. **安裝。** 從[最新版本](https://github.com/jbrick2070/obs-playlister/releases/latest)下載適合你系統的檔案並執行（詳見英文的 [Install](../../README.md#install)），然後重新啟動 OBS。
2. **新增來源。** 在 OBS 的 **來源** 面板中按 **+**，選擇 **Playlister**，然後按 **確定**。
3. **新增要播放的內容。** 在開啟的視窗中，按 **播放清單** 右側的 **+**，選擇 **新增檔案**（影片、音訊、影像或播放清單檔案）、**新增目錄**（資料夾；其中的新檔案會自動加入）或 **新增路徑／URL**（網址）。按 **確定**。

就這麼簡單。其場景一進入 **展示** 就開始播放。無需變更任何設定：清單會循環，資料夾會被監看，Playlister 會自行判斷每一列是檔案、資料夾、播放清單檔案還是網址。

在 **工作室模式** 下，新來源會在 **預覽** 場景中等待：**狀態** 顯示「等待中：其場景進入展示後開始播放。」，直到你用 **淡入淡出** 或 **直接轉場** 把該場景送到 **展示**。
