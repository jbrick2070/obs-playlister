# Playlister

OBS Studio 33 이상용 재생목록 소스입니다. 동영상, 오디오, 이미지 파일과 폴더, 재생목록 파일, 웹 주소를 차례로 재생하며, 목록을 편집해도 재생 중인 클립이 처음부터 다시 시작되지 않습니다.

<img src="../../docs/images/quick-start-steps.svg" alt="Playlister 3단계: 1, 설치하고 OBS를 다시 시작합니다. 2, 소스 목록에서 +를 누르고 Playlister를 선택한 뒤 확인을 누릅니다. 3, 재생목록 오른쪽의 +를 눌러 파일, 폴더 또는 웹 주소를 추가합니다. 장면이 프로그램에 들어오면 재생됩니다." width="900">

1. **설치합니다.** [최신 릴리스](https://github.com/jbrick2070/obs-playlister/releases/latest)에서 사용 중인 시스템용 파일을 내려받아 실행하고(자세한 내용은 영어로 된 [Install](../../README.md#install) 참고) OBS를 다시 시작합니다.
2. **소스를 추가합니다.** OBS의 **소스 목록**에서 **+**를 누르고 **Playlister**를 선택한 뒤 **확인**을 누릅니다.
3. **재생할 항목을 추가합니다.** 열린 창에서 **재생목록** 오른쪽의 **+**를 누르고 **파일 추가**(동영상, 오디오, 이미지 또는 재생목록 파일), **디렉토리 추가**(폴더. 새 파일은 자동으로 추가됩니다) 또는 **경로 또는 URL 추가**(웹 주소)를 선택합니다. **확인**을 누릅니다.

이제 끝입니다. 장면이 **프로그램**에 들어오면 바로 재생됩니다. 바꿔야 할 설정은 없습니다. 목록은 반복되고, 폴더는 감시되며, Playlister가 각 행이 파일, 폴더, 재생목록 파일, 웹 주소 중 무엇인지 스스로 알아냅니다.

**스튜디오 모드**에서는 새 소스가 **미리보기** 장면에서 기다립니다. 그 장면을 **서서히 사라지기** 또는 **자르기**로 **프로그램**에 보낼 때까지 **상태**에 "대기 중: 장면이 프로그램에 들어오면 재생됩니다."라고 표시됩니다.
