# Playlister

Una fonte playlist per OBS Studio 33 e versioni successive. Riproduce file video, audio e immagini, cartelle, file di playlist e indirizzi web, uno dopo l'altro, e modificare la lista non fa ripartire la clip in riproduzione.

<img src="../../docs/images/quick-start-steps.svg" alt="Playlister in tre passi: 1, installalo e riavvia OBS; 2, in Fonti premi +, scegli Playlister e premi OK; 3, premi + a destra di Playlist e aggiungi file, una cartella o un indirizzo web. Parte quando la sua scena è in Programma." width="900">

1. **Installalo.** Scarica il file per il tuo sistema dall'[ultima versione](https://github.com/jbrick2070/obs-playlister/releases/latest), eseguilo (dettagli in [Install](../../README.md#install), in inglese), poi riavvia OBS.
2. **Aggiungi la fonte.** In OBS, nel riquadro **Fonti**, premi **+**, scegli **Playlister** e premi **OK**.
3. **Aggiungi cosa vuoi riprodurre.** Nella finestra che si apre, premi **+** a destra di **Playlist** e scegli **Aggiungi dei file** (video, audio, immagini o un file di playlist), **Aggiungi una cartella** (i nuovi file al suo interno si aggiungono da soli) o **Aggiungi un percorso/URL** (un indirizzo web). Premi **OK**.

Fatto. Parte appena la sua scena è in **Programma**. Non serve cambiare nessuna impostazione: la lista si ripete, le cartelle sono sorvegliate e Playlister capisce da solo se una riga è un file, una cartella, un file di playlist o un indirizzo web.

In **Modalità studio** una nuova fonte attende nella scena in **Anteprima**: **Stato** dice "In attesa: parte quando la sua scena è in Programma." finché non porti quella scena in **Programma** con **Dissolvenza** o **Taglio**.
