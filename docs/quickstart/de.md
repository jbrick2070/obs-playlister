# Playlister

Eine Wiedergabelisten-Quelle für OBS Studio 33 und neuer. Sie spielt Video-, Audio- und Bilddateien, Ordner, Wiedergabelisten-Dateien und Webadressen über die eigene Medienquelle von OBS nacheinander ab, und eine Änderung der Liste startet den laufenden Clip nicht neu.

<img src="../../docs/images/quick-start-steps.svg" alt="Playlister in drei Schritten: 1, installieren und OBS neu starten; 2, unter Quellen auf + klicken, Playlister wählen und OK klicken; 3, rechts neben Wiedergabeliste auf + klicken und Dateien, einen Ordner oder eine Webadresse hinzufügen. Die Wiedergabe beginnt, sobald die Szene im Programm ist." width="900">

1. **Installieren.** Laden Sie die Datei für Ihr System aus dem [neuesten Release](https://github.com/jbrick2070/obs-playlister/releases/latest) herunter, führen Sie sie aus (Details unter [Install](../../README.md#install), auf Englisch) und starten Sie OBS neu.
2. **Quelle hinzufügen.** Klicken Sie in OBS im Feld **Quellen** auf **+**, wählen Sie **Playlister** und klicken Sie auf **OK**.
3. **Inhalte hinzufügen.** Klicken Sie im geöffneten Fenster rechts neben **Wiedergabeliste** auf **+** und wählen Sie **Dateien hinzufügen** (Video, Audio, Bilder oder eine Wiedergabelisten-Datei), **Ordner hinzufügen** (neue Dateien darin kommen von selbst dazu) oder **Pfad/URL hinzufügen** (eine Webadresse). Klicken Sie auf **OK**.

Das war's. Die Wiedergabe beginnt, sobald die Szene im **Programm** ist. Keine Einstellung muss geändert werden: Die Liste wird wiederholt, Ordner werden beobachtet, und Playlister erkennt selbst, ob eine Zeile eine Datei, ein Ordner, eine Wiedergabelisten-Datei oder eine Webadresse ist.

Im **Studio-Modus** wartet eine neue Quelle in der Szene der **Vorschau**: **Status** zeigt „Wartet: spielt, sobald die Szene im Programm ist.“, bis Sie diese Szene mit **Überblende** oder **Schnitt** ins **Programm** bringen.
